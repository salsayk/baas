Timese (BaaS) – Application Architecture

Bill Management for SMBs — full-stack Next.js app with Google OAuth, PostgreSQL, and multi-tenant accounts. Markdown source: architecture.md

Overview Technologies System diagram Data model Auth flow Pages API Components

1. Overview

Timese helps account owners manage service offices, their customers, projects, contracts (milestones, hourly, success), subscriptions, and service office users with fine-grained data authorization.

Tenancy is enforced at the accounts layer: every API query joins through accounts.user_id so users only access their own data.

2. Technologies (by layer)

Frontend

  • React 19 + Next.js 16 App Router
  • TypeScript 5.9
  • Tailwind CSS 4
  • Contexts: Auth, Theme, Language, Translation
  • Client modals under database/
  • Geist fonts, Radix slot, CVA UI primitives

Backend

  • Next.js Route Handlers (app/api/*)
  • NextAuth 4 — Google OAuth, JWT session
  • proxy.ts — page-level auth gate
  • getAuthenticatedUser() — API auth
  • Nodemailer / Resend (email verification)
  • LangChain (optional GitHub summarizer)

Database

  • PostgreSQL via pg 8.18
  • Config: PG* env or db-config.json
  • SQL scripts per entity in database/
  • Runner: database/run-sql.mjs

sequenceDiagram

  participant B as Browser
  participant P as proxy.ts
  participant N as NextAuth
  participant A as API route
  participant D as PostgreSQL

  B->>P: HTTP request
  alt No session cookie
    P-->>B: Redirect to /
  else Session valid

  end
  U->>B: Sign in with Google
  B->>N: OAuth flow
  N->>D: Upsert users row
  N-->>B: JWT session cookie
  B->>A: fetch /api/...
  A->>N: getServerSession
  A->>D: Query with user_id filter
  A-->>B: JSON response
